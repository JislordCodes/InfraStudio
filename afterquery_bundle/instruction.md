Add a clash detection engine in `frontend/src/spatial` covering `architectural`, `structural`, `mechanical`, `electrical`, `plumbing`, `generic` elements.

`createAxisAlignedBoundingBox(min,max)` returns `{min,max,size,center}`. Every coordinate (incl. closestPoints) is an `[x,y,z]` array, not an object. min>max throws Error matching `Invalid bounding box coordinates`.

`detectClashes(elements,options?)` takes `SpatialElement[]` (`{id,name,discipline,boundingBox,properties?}`), returns `{clashes,summary:{total,hard,clearance,processedElements}}`. `ClashRecord`: `{id,elementA,elementB,type,severity,distance,penetrationDepth?,intersectionBox?}` — elementA/elementB are full elements, not ids. Overlaps get `type:'hard'`, `severity:'critical'`, `distance:0`, minimum-axis `penetrationDepth`, `intersectionBox`. Boxes within `options.tolerance` get `type:'clearance'`: `'high'` under half tolerance, else `'medium'`. `options.includeTouching` gates zero-distance contacts; `options.minSeverity` drops below that rank (`critical`>`high`>`medium`>`low`); `options.filterDisciplines` keeps a pair only if both listed. Off by default.

`calculateClearance(elemA,elemB,requiredClearance)` returns `{distance,hasConflict,closestPoints:{pointA,pointB}}`; hasConflict is distance<requiredClearance; each point is the other's center clamped into its own box. `buildClearanceMatrix(elements,requiredClearance,maxDistanceCutoff?)` returns symmetric `{elementIds,matrix,violations}` (plain ids); past-cutoff becomes `Infinity`.

`groupClashes(clashes,groupBy)` buckets clashes by severity, element (both participant ids), discipline (sorted hyphenated pairs), or cluster (via `findClashClusters`, smallest elementId keyed). `exportClashReport(result,format)` gives 2-space JSON, or text headed `SPATIAL CLASH DETECTION REPORT` with `Total Clashes:`/`Hard Clashes:` lines. `findClashClusters(clashes)` merges linked elements into `{elementIds,clashCount}` groups, ids ascending. `suggestResolution(clash)` needs hard clashes, else throws `suggestResolution requires a hard clash`; returns axis(0/1/2, least penetration), direction(1 if elementB's center≥elementA's there, else -1), distance(penetrationDepth). `rankClusters(clashes)` sorts by worst severity, more clashCount, smallest elementId; `worstCluster` is its top entry, or null.

`createClashSession(options?)`: `add`/`remove` return the session (chainable); `results()` runs detection and remembers clash ids; `delta()` reports ids added/removed since results().

Add analytics under `frontend/src/spatial/analytics` for clash history. `createClashJournal()` returns a journal: `record(result,timestamp?)` appends a snapshot (timestamp defaults to count recorded so far); `history()` returns them in order; `since(timestamp)` filters to snapshots after it. `analyzeHotspots(journal,options?)` scans history: per clashed element, counts appearances, tracks worst severity, compares first-vs-last severity for worsening/improving/stable; sorted by count, severity, id. `options.minOccurrences`/`options.limit` filter and cap results.
