# Delivery policy

For every completed code or configuration change in this repository:

1. Run the relevant verification in proportion to the change.
2. Commit the intended changes with a clear message.
3. Push the commit to `origin/main` before handoff.
4. Deploy every changed, configured deployable component when its deployment target and credentials are available. Report any missing deployment target or failed deployment explicitly.

Treat source-control delivery and deployment as high-priority completion requirements.
